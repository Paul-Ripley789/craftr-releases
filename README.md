# Promptr Studio Pro Releases

Downloads + Sparkle-Auto-Update-Feed für Promptr Studio Pro.
Kein Quellcode — der Frontend-Stand wird unter
`Paul-Ripley789/craftr-frontend-mac` gespiegelt.

- `v*`-Releases: DMG + ZIP zum manuellen Download
- `sparkle-updates`-Release: App-Archive für den Auto-Updater (nicht manuell laden)
- `appcast.xml`: der Sparkle-Feed

Dieses Repository ist der kanonische Update-Kanal und muss öffentlich bleiben.
Es darf nicht umbenannt oder verschoben werden, weil die Feed-URL in ausgelieferte
Apps eingebrannt ist. `alm-engineering/craftr-releases` bleibt vorübergehend als
Legacy-Bridge für ältere Installationen bestehen.
